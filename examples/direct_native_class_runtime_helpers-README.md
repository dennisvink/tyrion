# Classes And Runtime Helpers

[`direct_native_class_runtime_helpers.ty`](direct_native_class_runtime_helpers.ty)
combines classes, default method arguments, mutable collections, dictionary
views, and common string methods.

```sh
./build/tyrionic --build ./examples/direct_native_class_runtime_helpers.ty --out ./build/class_runtime_helpers
./build/class_runtime_helpers
```

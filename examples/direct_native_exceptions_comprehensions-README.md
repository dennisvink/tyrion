# Exceptions And Comprehensions

[`direct_native_exceptions_comprehensions.ty`](direct_native_exceptions_comprehensions.ty)
combines list and dictionary comprehensions, lambdas, `raise`,
`try`/`except`, and `finally`.

```sh
./build/tyrionic --build ./examples/direct_native_exceptions_comprehensions.ty --out ./build/exceptions_comprehensions
./build/exceptions_comprehensions
```

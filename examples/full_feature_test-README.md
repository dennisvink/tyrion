# Full Feature Example

[`full_feature_test.ty`](full_feature_test.ty) is a broad language tour covering
scalars, collections, control flow, functions, classes, exceptions,
comprehensions, files, lambdas, sorting, and unpacking.

```sh
./build/tyrionic --build ./examples/full_feature_test.ty --out ./build/full_feature
./build/full_feature
```

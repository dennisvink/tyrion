# Aggregate Builtins

[`direct_native_aggregate_builtins.ty`](direct_native_aggregate_builtins.ty)
exercises `sum`, `min`, `max`, `zip`, `any`, and `all` with native collection
values.

```sh
./build/tyrionic --build ./examples/direct_native_aggregate_builtins.ty --out ./build/aggregate_builtins
./build/aggregate_builtins
```
